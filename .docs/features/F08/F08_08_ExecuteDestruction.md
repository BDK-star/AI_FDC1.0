## 2. 节点目标

- **执行**销毁动作（现场粉碎、委托销毁、电子档逻辑删除/脱库等，按载体与合规要求分支）。
- 登记**实施结果**：完成时间、方式、监销人、回执/影像；将档案状态置为**已销毁**或等价终态。
- 触发**后续动作**：销毁报告生成、审计归档、受限下载清理、索引失效等（可与异步任务队列结合）。

## 3. 参与角色

- 实施人 / 监销人
- 系统任务：报告生成、存储清理（权限见 `03_Security.md`）

## 4. 输入 / 输出

| 类型 | 内容 |
|---|---|
| 输入 | 出库完成确认 + 冻结清单；实施方式、回执编号、附件（照片、第三方证明） |
| 输出 | 实施销毁记录；档案/文档终态；销毁报告（文件存储路径）；审计日志 |

## 5. 业务规则（草案）

- **R-01**：**不可逆**：确认完成前须二次确认；完成后禁止恢复业务借阅（物理恢复走灾备流程，不在 F08 范围）。
- **R-02**：部分完成（批量中部分失败）时：重试策略、失败明细列表、是否阻断整单闭环。
- **R-03**：与 `fdc_disposal_record_t`（或等价表）**一一或一对多**映射，保证可追溯。

## 6. 页面与 API（占位）

- 实施登记页、批量勾选完成、上传回执。
- API：确认实施完成、查询实施状态、下载销毁报告。
