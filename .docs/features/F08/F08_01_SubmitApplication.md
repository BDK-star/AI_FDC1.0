## 2. 节点目标

- 由**文档管理员**发起销毁申请，维护申请主信息、销毁计划、监督信息与销毁清单。
- 支持**草稿**与**正式提交**；提交后进入审核申请环节。

## 3. 参与角色

- 申请人：文档管理员（发起与提交）。
- 系统：校验、生成单号、写审计

## 4. 输入 / 输出

| 类型 | 内容 |
|---|---|
| 输入 | 基本信息、销毁计划、销毁监督、销毁清单、抄送人 |
| 输出 | 销毁申请主单（草稿或已提交状态）；申请明细与档案引用关系 |

## 5. 页面分区与填写内容（提交申请页）

### 5.1 分区一：基本信息填写

| 序号 | 字段 | 规则 |
|---:|---|---|
| 1 | 申请标题 | 必填，文本输入 |
| 2 | 申请说明 | 必填，多行文本 |
| 3 | 销毁方式 | 必填，单选：`粉碎` / `焚烧` / `溶解` / `其他` |
| 4 | 销毁方式-其他说明 | 当销毁方式=`其他`时必填 |
| 5 | 销毁场地 | 必填，单选：`华为办公场地` / `外部供应场地` / `其他` |
| 6 | 销毁场地-其他说明 | 当销毁场地=`其他`时必填 |

### 5.2 分区二：销毁计划

> 计划节点固定为 4 项，每项均需填写**责任人**与**计划时间**。

| 计划节点 | 责任人 | 计划时间 |
|---|---|---|
| 文档实物整理 | 必填 | 必填 |
| 文档实物出库 | 必填 | 必填 |
| 现场实施销毁 | 必填 | 必填 |
| 销毁记录归档 | 必填 | 必填 |

### 5.3 分区三：销毁监督

| 字段 | 规则 |
|---|---|
| 部门 | 必填 |
| 角色 | 必填，选项：`销毁申请人` / `销毁监督人` |
| 姓名 | 必填 |
| 备注 | 选填 |

### 5.4 分区四：销毁清单

支持两种来源，允许并存：

1. **系统内选择**：从系统中选择“文档管理员所属组织”下的到期文档。  
2. **附件上传**：上传系统外文档信息（模板与字段另行在本文件后续版本补充）。

### 5.5 分区五：抄送人

- 抄送人可多选，选填。
- 提交后为流程消息通知对象，不作为审批节点处理人。

### 5.6 页面主操作

- 主按钮：`提交申请`
- 辅助按钮（建议）：`保存草稿`

## 6. 业务规则

- **R-01 发起权限**：仅文档管理员可发起提交申请。
- **R-02 条件必填**：选择“其他”时，必须填写对应“其他说明”。
- **R-03 计划完整性**：4 个计划节点均需填写责任人与计划时间。
- **R-04 清单完整性**：提交前销毁清单至少包含 1 条文档（系统内选择或附件导入后解析成功）。
- **R-05 提交结果**：点击 `提交申请` 并校验通过后，主单状态更新为“待审核申请”，进入 `F08_02_ReviewApplication.md`。
- **R-06 单号生成**：申请提交时生成申请单号，规则为 `DT` + 申请日期(`yyyyMMdd`) + 五位流水号（同日递增）。

## 9. 验收要点

- 仅文档管理员可以看到并使用“提交申请”入口。
- “销毁方式=其他”与“销毁场地=其他”时，系统强制校验“其他说明”必填。
- 4 个销毁计划节点都填写完成后，才允许提交。
- 销毁清单为空时，提交失败并给出明确提示。
- 提交成功后生成单号（格式示例：`DT2026042700001`），状态变为“待审核申请”。
