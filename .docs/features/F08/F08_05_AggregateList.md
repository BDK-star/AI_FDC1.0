## 2. 节点目标

- 将已通过**双重鉴定**的明细固化为**正式销毁汇总清单**（带版本号或快照 ID）。
- 清单**冻结**后作为后续销毁审批、出库核对、实施销毁的**唯一依据**（变更需走变更流程或退回，待订）。

## 3. 参与角色

- 清单编制人（可与综合鉴定同角色或专职）
- 复核人（若与编制分离，待订）

## 4. 输入 / 输出

| 类型 | 内容 |
|---|---|
| 输入 | 鉴定通过的明细集合；可调整的展示列与排序；备注 |
| 输出 | 汇总清单版本记录；PDF/Excel 导出（可选）；主单状态「待销毁审批」 |

## 5. 业务规则（草案）

- **R-01**：清单生成前自动剔除「不同意/暂缓」明细，并生成剔除报告供查阅。
- **R-02**：冻结后禁止增删明细；若必须调整，须**解锁策略**（审批解锁或退回至鉴定，待订）。
- **R-03**：清单需包含：档案标识、题名、保管期限、鉴定结论摘要、库位/载体类型等（列清单对齐 `01_DataModel.md`）。

## 6. 页面与 API（占位）

- 清单预览、生成/冻结、导出、版本历史。
- API：生成清单、冻结、下载、查询版本。
