## 2. 节点目标

- 由**有权签批人**对冻结后的汇总清单及鉴定链进行**销毁决策审批**。
- 结论：**同意销毁**（进入出库审批）、**不同意**（终止或退回，待订）。

## 3. 参与角色

- 销毁审批人（可多级或会签，策略同 `02_Workflow.md` / F07 多人审批模式）

## 4. 输入 / 输出

| 类型 | 内容 |
|---|---|
| 输入 | 冻结清单只读视图；审批意见；电子签章（若集成） |
| 输出 | 审批记录；主单状态「待出库审批」或终态 |

## 5. 业务规则（草案）

- **R-01**：审批必须基于**已冻结清单版本**；切换版本需重新触发审批或记录变更单。
- **R-02**：驳回/不同意时的数据状态：明细是否释放、申请是否可改，与 `F08_01`～`F08_05` 回退规则一致。
- **R-03**：审批 SLA、催办、转审（若平台统一支持）。

## 6. 页面与 API（占位）

- 审批待办、清单只读穿透至档案摘要、同意/驳回。
- API：审批提交、审批历史、待办查询。

## 8. 验收要点（草案）

- 未冻结清单不可提交销毁审批；通过后进入出库审批且清单仍只读。
