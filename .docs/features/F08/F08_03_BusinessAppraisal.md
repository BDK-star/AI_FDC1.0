## 2. 节点目标

- 由**业务归口**对拟销毁档案进行鉴定：是否仍具业务保存价值、是否与账务/诉讼/监管要求冲突等。
- 支持**按明细**给出鉴定结论（同意销毁 / 暂缓 / 不同意）及依据说明。

## 3. 参与角色

- 业务鉴定人（可按业务模块/组织路由，待订）
- 必要时申请人仅只读查看进度

## 4. 输入 / 输出

| 类型 | 内容 |
|---|---|
| 输入 | 审核通过的申请及明细；鉴定意见、依据、附件 |
| 输出 | 明细级或批次级鉴定结果；主单进入「待综合鉴定」的前置条件满足标记 |

## 5. 业务规则（草案）

- **R-01**：存在「不同意」或「暂缓」的明细时，汇总清单生成规则（整单挂起 vs 剔除明细，待产品定稿）。
- **R-02**：与自动规则的关系：系统仅可**推荐**候选档，**不得**绕过人工鉴定结论写最终状态。
- **R-03**：鉴定完成门槛：全部明细已鉴定或已明确剔除策略。

## 6. 页面与 API（占位）

- 鉴定工作台、明细列表批量操作、结论录入。
- API：提交鉴定、查询鉴定历史。
