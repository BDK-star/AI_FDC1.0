## 2. 节点目标

- 对文档管理员提交的销毁申请进行审核，审核人只处理**自己负责的审核任务范围**。
- 审核结论仅两种：**通过**或**驳回**，并填写审核意见。

## 3. 参与角色

- 审核人（当前处理人）
- 文档管理员（申请发起人，接收审核结果）

## 4. 输入 / 输出

| 类型 | 内容 |
|---|---|
| 输入 | 申请主单 + 明细快照；审核结果（通过/驳回）；审核意见；抄送人（可多人） |
| 输出 | 审核记录；主单状态迁移；抄送通知 |

## 5. 页面分区与填写内容（审核申请页）

### 5.1 审核内容区

- 展示提交申请节点形成的内容（基本信息、销毁计划、销毁监督、销毁清单）。
- 审核人仅可处理分配给自己的审核任务；不在本人处理范围的部分仅可查看。

### 5.2 审核结论区

| 字段 | 规则 |
|---|---|
| 审核结果 | 必填，单选：`通过` / `驳回` |
| 审核意见 | 必填，多行文本 |
| 抄送人 | 选填，可多选 |

### 5.3 页面操作区

- 主按钮：`提交`（位于页面底部）。

## 6. 业务规则

- **R-01 本人范围**：审核人仅可审核本人待办任务，不能代替他人提交审核结果。
- **R-02 结果约束**：审核结果仅允许“通过”或“驳回”。
- **R-03 意见必填**：提交时必须填写审核意见。
- **R-04 抄送规则**：抄送人为通知对象，可多人，不参与该节点审批结果判定。
- **R-05 提交位置**：审核动作通过页面底部 `提交` 按钮触发。
- **R-06 流转规则**：结果为“通过”则进入 `F08_03_BusinessAppraisal.md`；结果为“驳回”则流程进入驳回分支（终态或按工作流配置回退）。

## 9. 验收要点

- 审核人打开待办时，只能提交本人负责的审核任务。
- 审核结果只允许选择“通过”或“驳回”。
- 未填写审核意见时，点击底部 `提交` 不允许通过校验。
- 抄送人支持多选，且不影响审批结果判定。
- 选择“通过”并提交后，主单进入“待业务鉴定”。
