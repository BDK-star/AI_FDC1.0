## 2. 节点目标

- 由**档案管理/综合职能**对保管期限、法规与制度要求进行复核，形成**综合鉴定结论**。
- 与业务鉴定结论**合并校验**：对冲突项给出处理路径（退回业务鉴定或剔除明细）。

## 3. 参与角色

- 综合鉴定人 / 档案管理员（角色以 `03_Security.md` 为准）

## 4. 输入 / 输出

| 类型 | 内容 |
|---|---|
| 输入 | 业务鉴定完成的明细及结论；保管期限、归档状态等系统字段 |
| 输出 | 综合鉴定记录；允许生成汇总清单的「冻结候选集」 |

## 5. 业务规则（草案）

- **R-01**：保管期限未满且无合法提前销毁依据的档案，**不得**进入汇总清单（硬拦截或强提示级别待订）。
- **R-02**：综合鉴定可**一次性退回**至业务鉴定，并携带原因。
- **R-03**：鉴定过程全量审计，关键字段变更留痕。

## 6. 页面与 API（占位）

- 综合鉴定视图（对照业务结论与系统元数据）、批量确认、退回。
- API：提交综合鉴定、查询、退回上一节点。
