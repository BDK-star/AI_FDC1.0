# F03_06 导入查询（工作空间）

> **文档结构对齐**：本章节章节划分与 `F03_05_MyExports.md` 一致，便于对照实现与验收。

**工作空间口径**：「导入查询」为**系统通用功能**（平台级导入任务中心），与文档查询列表页当前选择的文档类型、公司编码、业务模块等**无关**；任务列表按**当前登录用户**可见范围展示（管理员是否可见全量以 `/.docs/03_Security.md` 为准）。

**全系统通用**：凡具备权限的模块均可发起导入并产生任务记录（如文档查询批量导入、应归档数据维护、移交/批量调整等）；本页汇总展示，**不限于**文档查询（F03）使用。

## 1. 场景

- **S-01 查看导入任务列表**：进入工作空间「导入查询」页面，查看任务标识、导入时间、任务类型、状态、条数与耗时等
- **S-02 查看结果 / 重新查询 / 导出结果**：按任务状态与权限展示行内操作（当前页面实现）
- **S-03 删除任务（可选）**：按策略删除或逻辑删除任务记录及关联临时文件

## 2. 页面字段（当前页面实现）

| 列 | 说明 |
|---|---|
| 文件名称 | 上传文件名或系统生成名 |
| 导入任务类型 | 文档批量导入查询、应归档数据批量导入查询、应归档批量导入/调整等 |
| 导入时间 | 时间戳 |
| 导入状态 | 成功 / 失败 / 处理中 / 部分成功（示例） |
| 导入总条数 / 成功条数 | 数值 |
| 运行时间 / 总耗时 | 展示用 |
| 导入结果 | 结果查询、重新查询、结果导出等操作入口 |

## 3. 规则与策略

- **R-MI-001 可见性**：默认仅展示当前用户任务（扩展规则见安全文档）。
- **R-MI-002 调用方与任务归属**：各业务模块导入入口均是调用方；任务统一沉淀到工作空间导入查询。
- **R-MI-003 删除与留存**：删除后列表不可见；文件与临时数据按留存策略清理。
- **R-MI-004 任务类型**：导入查询任务在 `workspace io-jobs` 中通过 `jobType` 区分（如 `IMPORT_QUERY`）。

## 4. 接口（代码对齐）

> 当前实现统一在 `workspace io-jobs` 资源下。

| 资源路径 | 方法 | 用途 |
|---|---|---|
| 资源路径 | 方法 | 用途 | 代码位置 |
|---|---|---|---|
| `FDC_URL/api/workspace/io-jobs/query` | POST | 工作空间任务分页查询（含导入查询） | `WorkspaceIoJobController.query` |
| `FDC_URL/api/workspace/io-jobs/{jobId}` | GET | 任务详情 | `WorkspaceIoJobController.getById` |
| `FDC_URL/api/workspace/io-jobs/{jobId}` | DELETE | 删除任务 | `WorkspaceIoJobController.delete` |
| `FDC_URL/api/workspace/io-jobs/{jobId}/import-result` | GET | 导入结果文件下载 | `WorkspaceIoJobController.downloadImportResult` |
| `FDC_URL/api/workspace/io-jobs/{jobId}/import-query-results` | GET | 导入查询结果明细 | `WorkspaceIoJobController.listImportQueryResults` |

## 5. 验收标准（AC）

- **AC-01**：用户在工作空间「导入查询」可见本人导入任务，且列表**不要求**先选择文档类型或公司。  
- **AC-02**：任务状态与条数、耗时等字段展示与后端一致；失败时可查看原因或下载失败明细（若实现提供）。  
- **AC-03**：删除（若提供）后任务不再出现在当前用户列表中。  

## 6. 权限与安全

- 列表、详情、下载均执行任务归属校验。
- 管理员越权查看策略须在 `/.docs/03_Security.md` 明确后生效。
- 审计字段：任务ID、jobType、操作者、动作、结果、时间。
