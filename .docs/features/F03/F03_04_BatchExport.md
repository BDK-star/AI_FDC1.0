# F03_04 批量导出

> 执行口径：仅以当前页面行为与后端接口实现为准。

**与导出查询的关系**：导出采用**全系统共用**的异步任务与 `export-tasks`（见 `F03_05` / 导出查询）。本节描述的是 **F03 文档查询列表**作为**调用方之一**发起导出的交互；其他模块若接入同一任务中心，复用同一套任务列表与下载能力，而非另建「仅文档查询可用」的导出体系。

## 1. 场景

- **S-01 从文档查询列表发起导出**
  - **输入**：N条勾选记录（当前实现要求）
  - **处理**：
    - N条：导出“勾选集合”
  - **输出**：创建导出任务；弹窗提示“导出提交成功…稍后到 导入导出 > 我的导出 查看”

## 2. 交互规格（当前实现）

### 2.1 成功提示弹窗

- **标题**：提示（Info）
- **内容**：
  - 绿色对钩图标
  - 文案：导出提交成功，系统正在处理，稍后请到 **导入导出 > 我的导出** 中查看导出结果。
  - 文案中的“导入导出 > 我的导出”为可点击链接，点击跳转我的导出页
- **按钮**：确定（Confirm）—关闭弹窗

## 3. 规则与策略

- **R-EX-001 权限控制**
  - 具备“文档列表导出/导出权限”才可发起导出
  - 无权限：按钮置灰或不可见（以 `/.docs/03_Security.md` 为准）

- **R-EX-002 导出内容定义**
  - 当前实现：仅导出勾选集合（`docIds` 必填）
  - 未勾选时应前端拦截并提示“请先选择至少一条记录”

- **R-EX-003 异步任务**
  - 导出采用异步任务；前端仅拿到 `export_task_id`
  - 后续在“我的导出”轮询或刷新查看状态

## 4. 接口规范（代码对齐）

> 当前提交导出任务接口在 `archive-management` 资源下。

| 资源路径 | 方法 | 用途 | 关键约束 |
|---|---|---|---|
| `FDC_URL/api/archive-management/pending-documents/export-jobs` | POST | 提交导出任务 | 请求体必须包含 `docIds` |
| `FDC_URL/api/workspace/io-jobs/query` | POST | 查询导出任务列表 | `jobType=EXPORT_QUERY` |
| `FDC_URL/api/workspace/io-jobs/{jobId}/export-file` | GET | 下载导出文件 | 任务状态需可下载 |

## 5. 可观测性与审计

- 记录：发起人、筛选条件摘要/勾选数量、导出类型、结果文件大小、完成时间、失败原因。

## 6. 验收标准（AC）

- **AC-01**：未勾选记录点击“批量导出”时，系统提示需先勾选记录，不创建任务。  
- **AC-02**：勾选N条记录点击“批量导出”后，成功创建任务并可在“我的导出”查看。  
- **AC-03**：导出任务状态可从处理中流转为已完成/失败。  

## 7. 权限与安全

- 权限点：文档导出、任务下载、任务删除。
- 审计字段：用户、docIds数量、任务ID、动作、结果。
- 建议：导出提交接口支持幂等键以减少重复任务。

## 8. 测试计划

| 用例ID | 场景 | 期望结果 |
|---|---|---|
| TC-EX-01 | 未勾选导出 | 前端拦截，不发起任务 |
| TC-EX-02 | 勾选导出 | 返回任务ID，列表可见 |
| TC-EX-03 | 导出文件下载 | 状态为完成时可下载 |
