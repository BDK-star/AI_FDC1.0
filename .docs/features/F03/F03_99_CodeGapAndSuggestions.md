# F03 文档与代码差异清单（2026-04）

## 1. 差异清单

| 编号 | 差异点 | 文档原口径 | 当前代码实现 | 处理策略 |
|---|---|---|---|---|
| GAP-01 | 批量导出未勾选行为 | 未勾选可按当前筛选导出 | 导出接口要求 `docIds` 必填 | 规格已改为“必须勾选”；后续如要恢复需扩展接口 |
| GAP-02 | 附件预览形态 | 返回外部 EDM 预览入口 | 预览接口直接返回资源流 | 规格已统一为流式预览 |
| GAP-03 | 我的草稿资源模型 | 独立 `/drafts` 资源 | 通过 `pending-documents/query + submitMode=DRAFT + archives/{id}` 组合实现 | 规格已改为组合模式 |
| GAP-04 | 导出/导入查询任务资源 | `export-tasks` / `workspace-io-jobs` 建议并存 | 统一 `workspace/io-jobs` | 规格统一到 `workspace/io-jobs` |
| GAP-05 | 查询筛选字段覆盖 | 业务期望存在更多筛选项 | 部分字段后端 DTO 不支持 | 前端按后端可用字段集显示，剩余列为待扩展项 |

## 2. 建议迭代项

- 建议 1：为批量导出新增“按筛选导出”模式（无 `docIds` 时接收筛选快照并异步导出）。
- 建议 2：统一查询入口，逐步收敛 `pending-documents/query` 与 `create/query` 双线并存。
- 建议 3：将 `F03_01` 的筛选字段分为“已实现/待实现”两张表，避免误导开发和测试。
- 建议 4：在 `/.docs/03_Security.md` 完整补登记 F03 按钮级 `perm_code`。

## 3. 影响范围

- 产品：需确认“导出未勾选是否必须支持”。
- 前端：需以当前接口能力调整按钮可用态与提示文案。
- 后端：如恢复历史口径，需要新增导出任务构建逻辑与筛选快照存储。
- 测试：回归用例应以本清单为准更新断言。

## 4. 已确认口径（2026-04-27）

- 导出任务模型以实际数据库为准：使用 `fdc_workspace_io_job_t`。
- `fdc_document_t` 以实际数据库为准，并按业务模块配置口径执行“先选字段类型再选字段池”：文本/数据字典/是否 -> `attr1~40`，数字 -> `attr41~60`，日期 -> `attr61~80`，日期时间 -> `attr81~100`。
- `fdc_document_attach_t` 以实际数据库为准，并按同口径执行：文本/数据字典/是否 -> `attribute1~20`，数字 -> `attribute21~30`，日期 -> `attribute31~40`，日期时间 -> `attribute41~50`。
- `delete_flag` 在任何表中统一按 `NVARCHAR2(1)` 口径执行。
- 时间字段口径：非档期字段统一 `TIMESTAMP`。
- 命名口径差异：统一以实际数据库主线命名为准。
