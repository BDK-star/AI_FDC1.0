# F03_05 我的导出

> 执行口径：仅以当前代码实现为准。

**工作空间口径**：菜单或工作空间中亦称「**导出查询**」。本能力与文档查询列表页上的文档类型、公司编码、业务模块等筛选条件**无绑定关系**；仅按当前用户（及 `/.docs/03_Security.md` 约定的 RBAC扩展）展示导出任务。

**全系统通用**：导出任务中心服务于**整个平台**；文档查询「批量导出」、其他业务列表或后台作业均可创建任务，并在本页（导出查询/我的导出）统一查看，**并非**文档查询专属功能。

## 1. 场景

- **S-01 查看导出任务列表**：进入“我的导出”页面，查看任务ID、导出时间、导出内容、状态、文件大小
- **S-02 下载导出文件**：状态为“已完成”时可下载
- **S-03 删除导出任务**：删除任务记录及其文件（按策略可能仅逻辑删除）

## 2. 页面字段（当前页面）

| 列 | 说明 |
|---|---|
| 导出任务ID | 如 `EXP-20260326-001` |
| 导出时间 | 时间戳 |
| 导出内容 | 如 “会计凭证 (3条)” |
| 状态 | 已完成 / 处理中 / 失败 / 已过期 |
| 文件大小 | 按后端返回与页面格式化展示 |
| 操作 | 下载、删除 |

## 3. 规则与策略

- **R-ME-001 可下载条件**：仅当任务状态为“已完成”且用户具备下载权限。
- **R-ME-002 删除策略**：删除后任务不可在列表中出现；文件若已生成，应同步清理或标记过期（与留存策略一致）。
- **R-ME-003 可见性**：仅展示“当前用户”任务（或按角色扩展为管理员可查看全量，需在安全文档明确）。

## 4. 接口（代码对齐）

> 当前实现统一在 `workspace io-jobs` 资源下，通过 `jobType=EXPORT_QUERY` 区分导出任务。

| 资源路径 | 方法 | 用途 | 代码位置 |
|---|---|---|---|
| `FDC_URL/api/workspace/io-jobs/query` | POST | 导出任务分页查询 | `WorkspaceIoJobController.query` |
| `FDC_URL/api/workspace/io-jobs/{jobId}` | GET | 导出任务详情 | `WorkspaceIoJobController.getById` |
| `FDC_URL/api/workspace/io-jobs/{jobId}/export-file` | GET | 下载导出文件 | `WorkspaceIoJobController.downloadExportFile` |
| `FDC_URL/api/workspace/io-jobs/{jobId}` | DELETE | 删除导出任务 | `WorkspaceIoJobController.delete` |

## 5. 验收标准（AC）

- **AC-01**：用户能在“我的导出”看到自己发起的导出任务，并按时间倒序展示。  
- **AC-02**：任务状态为“已完成”时，点击下载可成功下载文件。  
- **AC-03**：删除任务后，该任务不再出现在列表中；重复刷新保持一致。  

## 6. 权限与安全

- 仅可查看和操作有权限的数据范围内任务。
- 下载动作应校验任务状态与文件可用期。
- 审计至少记录：任务ID、操作人、下载/删除动作、结果与时间。

## 7. 测试计划

| TC-ME-02 | 已完成任务下载 | 下载成功且文件可打开 |
| TC-ME-03 | 删除任务 | 列表移除且重复刷新一致 |
